📊 GDPL3
GDPL3 is a web-based application designed to manage and display data related to GDP (Gross Domestic Product) statistics. Built with Flask, it provides users with an intuitive interface to view and analyze economic data.

🚀 Live Demo
Access the live application here: gdpl3.onrender.com

🛠️ Features
User-friendly interface for viewing GDP data

Responsive design compatible with various devices

Secure login system for user authentication

Integration with a SQLite database for data storage
